# Відновлення Chess Tournament Manager 1.2.88

Джерело: наданий користувачем XAPK. Основний APK: `com.danielmilano.roundrobinchesstournamentmanager.apk`, версія 1.2.88 / code 288.

SHA-256 основного APK: `df917ce20cebbc13ed3ad8d5d4704eb5a3262b07ff7b8282021af7f6763b267b`.

## Походження розрахунків

`apk-core.js` — ES2015-модуль, скомпільований TeaVM 0.12.3 з оригінального DEX через dex2jar 2.4. Це виконання відновленого байткоду, а не новий приблизний алгоритм.

| Функція | Оригінальні класи |
| --- | --- |
| Dutch Swiss | `C9.l1`, `C9.J1`, `C9.E1` |
| Гнучка швейцарка | `X9.I0`, `Y9` |
| Колові пари та кольори | `U8.D` |
| Арена | `x8.j`, `x8.d` |
| Командні пари й кольори дошок | `na.o`, `pa.q` |
| Посів сітки на вибування | `K8.x` |
| Бухгольц / Cut-1 / ЗБ | `D9.a` |
| Табличний Elo та історія змін | `W5.c`, `W5.a` |
| TRF16: форматування, читання й план імпорту | `C9.j2`, `C9.n2`, `F9.a` |

`engine.js` переводить вебдані у параметри цих класів та зберігає результати. Інтерфейс відтворено в HTML/CSS за ресурсами APK і знімками застосунку, з українською та англійською мовами. Android Compose, Room, Google Play та облікові служби в браузері не виконуються. Завершення етапів KO, відображення місць, вебсховище й історія реалізовані у JavaScript; це не твердження про перевірену тотожність кожного екрана чи кожного можливого турніру.

## Відтворення збірки

1. Витягти основний APK із наданого XAPK та перевірити SHA-256.
2. Перетворити всі DEX через dex2jar 2.4 у спільний `original-all.jar`.
3. Запустити `normalize_class_metadata.py`: прибрати суперечливі прапори `abstract + final` та виправити метадані `InnerClasses`.
4. Запустити `FixJvm.java` з ASM 9.7.1: нормалізувати версії класів, статичні посилання на методи інтерфейсів та JVM frames.
5. Зберегти результат як `bridge/original-bridge.jar`. Скомпілювати й додати до цього JAR два класи `f7/a.java`, `f7/l.java`: вони замінюють лише Android-джерело часу для створення записів турніру на `System.currentTimeMillis()`.
6. У `bridge` виконати `mvn package` під JDK 17. Результат: `target/web/apk-core.js`. Встановлені через Maven залежності визначені в `pom.xml`.

DAO-мости мають лише необхідні операції в пам’яті. Неочікуваний виклик бази даних спричиняє помилку. Перевірки ліцензії та авторизації не обходилися; вони не входять до турнірного мосту. APK, сторонні JAR та локальні налаштування проксі не зберігаються в репозиторії.

## Незалежна звірка

`tests/fixtures/apk-1.2.88.json` містить 94 відповіді оригінальних класів, виконаних JVM, які порівнюються з браузерним TeaVM-модулем. Перевірено кілька розмірів складу, турів, пропусків, кольорів, подвійне коло, команди, Elo, коефіцієнти, посів KO та TRF16. У гнучкій швейцарці випадковий вибір кольору за однакових переваг перевіряється без порядку кольорів. Це обмежений набір контрольних прикладів, а не доказ усіх можливих сценаріїв.

Окремі інтеграційні тести перевіряють повернення рейтингу, ручні пари, зміну учасників, результати командних дошок, імпорт/експорт TRF16 та захист збережень. Playwright перевіряє телефон, ПК, усі шість форматів, історію, мови й офлайн.
