# Турнір ♞

Мінімалістичний українськомовний робочий простір для організації шахового турніру. Статичний сайт працює без сервера та зберігає стан у `localStorage` браузера.

## Можливості

- додавання та видалення учасників;
- автоматичне формування пар за круговою системою;
- перемикання турів і запис результатів;
- автоматичний підрахунок перемог, нічиїх, поразок та очок;
- адаптивний інтерфейс для телефона й комп’ютера.

## Запуск локально

Відкрийте `index.html` у браузері або запустіть будь-який статичний HTTP-сервер у корені проєкту.

## Публікація на GitHub Pages

Workflow у `.github/workflows/pages.yml` публікує сайт після кожного пушу до `main`. У налаштуваннях репозиторію в розділі **Pages** потрібно вибрати **GitHub Actions** як джерело розгортання. Після першого успішного запуску сайт буде доступний за адресою `https://<власник>.github.io/<назва-репозиторію>/`.

Учасники та результати зберігаються локально у браузері відвідувача й не синхронізуються між пристроями.
