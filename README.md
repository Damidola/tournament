# Менеджер шахових турнірів

Робоча вебверсія для телефона та ПК: [відкрити сайт](https://damidola.github.io/tournament/).

Українська мова за замовчуванням; англійська перемикається в налаштуваннях. Пари поточного туру відкриваються одразу, результати вводяться великими кнопками. Контроль часу міститься в налаштуваннях.

## Турніри

- Коловий турнір в одне або два кола.
- На вибування: збалансований / випадковий посів, вибір переможця після нічиєї, матч за третє місце.
- Dutch Swiss, гнучка швейцарка, командна швейцарка та арена.
- Простий режим без рейтингу або рейтинги й статистика; класика, рапід, бліц та K-фактор.
- Каталог гравців, збережені списки й команди; склади команд на кожний тур.
- Звичайні результати, неявки, пропуски, зняття й додавання учасників у доступних форматах.
- Таблиця після вибраного туру, коефіцієнти з деталями, ручне редагування відкритих пар.
- Повернення до туру зі збереженням його результатів та скасуванням наступних. Відновлення попередньої версії з історії.
- JSON-копії, CSV, друк таблиці, TRF16 для індивідуальної швейцарки з перевіркою та імпортом зіграних турів.

Розрахунки й жеребкування виконуються через відновлений байткод APK 1.2.88. [Походження, збірка та межі перевірки](reverse-engineering/README.md). Це робочий порт; повна тотожність кожного Android-екрана та сервісу ще не підтверджена.

## Дані

Кожний результат зберігається перед підтвердженням. Дві локальні записи мають контрольну суму; останні 24 зміни турніру містять повні знімки. Застаріла вкладка не може перезаписати свіжі дані. Імпорт перевіряється до запису.

Після першого успішного завантаження сайт працює офлайн. Його можна додати на головний екран телефона. Дані зберігаються в цьому браузері; для перенесення використовуйте JSON. Google-вхід і хмарна синхронізація поки не реалізовані. Розрахований Elo є оцінкою за алгоритмом застосунку; каталог не замінює офіційні рейтингові списки FIDE.

Попередній інтерфейс залишено в `archive/pre-apk-reverse-2026-10-08`.

## Запуск і перевірки

Потрібен Node.js 24. У сайту немає серверних чи npm-залежностей.

```sh
npm test
python3 -m http.server 4173
```

Відкрийте `http://localhost:4173`. Для браузерних перевірок:

```sh
npm install --no-save --ignore-scripts playwright@1.56.1
CHROME_BIN=/usr/bin/chromium node tests/ui.cjs
```

GitHub Actions запускає тести та мобільні/десктопні сценарії перед публікацією `main` на GitHub Pages. У публічну збірку потрапляють лише файли сайту.
