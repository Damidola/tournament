# Менеджер шахових турнірів

Робоча вебверсія для телефона та ПК: [відкрити сайт](https://damidola.github.io/tournament/).

Українська мова за замовчуванням; англійська перемикається в налаштуваннях. Пари поточного туру відкриваються одразу, результати вводяться великими кнопками. Контроль часу міститься в налаштуваннях.

## Турніри

- Коловий турнір в одне або два кола.
- На вибування: збалансований / випадковий посів, вибір переможця після нічиєї, матч за третє місце.
- Dutch Swiss, гнучка швейцарка, командна швейцарка та арена.
- Простий режим без рейтингу або рейтинги й статистика; класика, рапід, бліц та K-фактор.
- Каталог гравців, збережені списки й команди; склади команд на кожний тур.
- Звичайні результати, неявки, пропуски, зняття й додавання учасників у доступних форматах.
- Таблиця після вибраного туру, коефіцієнти з деталями, ручне редагування відкритих пар.
- Повернення до туру зі збереженням його результатів та скасуванням наступних. Відновлення попередньої версії з історії.
- JSON-копії, CSV, друк таблиці, TRF16 для індивідуальної швейцарки з перевіркою та імпортом зіграних турів.

Розрахунки й жеребкування виконуються через відновлений байткод APK 1.2.88. [Походження, збірка та межі перевірки](reverse-engineering/README.md). Це робочий порт; повна тотожність кожного Android-екрана та сервісу ще не підтверджена.

## Дані

Кожний результат зберігається перед підтвердженням. Дві локальні записи мають контрольну суму; останні 24 зміни турніру містять повні знімки. Застаріла вкладка не може перезаписати свіжі дані. Імпорт перевіряється до запису.

Після першого успішного завантаження сайт працює офлайн. Його можна додати на головний екран телефона. Дані зберігаються в цьому браузері; для перенесення використовуйте JSON. Google-вхід і хмарна синхронізація поки не реалізовані. Розрахований Elo є оцінкою за алгоритмом застосунку; каталог не замінює офіційні рейтингові списки FIDE.

Попередній інтерфейс залишено в `archive/pre-apk-reverse-2026-10-08`.

## Запуск і перевірки

Потрібен Node.js 24. У сайту немає серверних чи npm-залежностей.

```sh
npm test
python3 -m http.server 4173
```

Відкрийте `http://localhost:4173`. Для браузерних перевірок:

```sh
npm install --no-save --ignore-scripts playwright@1.56.1
CHROME_BIN=/usr/bin/chromium node tests/ui.cjs
```

GitHub Actions перевіряє синтаксис і публікує `main` на GitHub Pages. Розширені перевірки запускаються вручну за потреби. У публічну збірку потрапляють лише файли сайту.

## Інтерфейс за наданими скриншотами

Екрани турнірів, гравців, статистики, облікового запису, інформації, вибору формату, налаштувань і результатів відтворено за дев’ятьма сторінками наданого screenshots.pdf. На телефоні основні екрани мають п’ять нижніх іконок; налаштування й тури — окрему компактну шапку без цього меню. Столики прокручуються разом зі сторінкою. Натискання результату зберігає позицію прокручування. Google-вхід і хмарна синхронізація поки недоступні; резервні копії у файл працюють.

Версія 3.2 використовує один файл `mobile.css`, світлу й темну палітри з наданих скриншотів, компактні форми та окремий екран місць. Посилання на ресурси містять номер версії. Після активації нової офлайн-оболонки відкриті сторінки старої версії автоматично переходять на нову; локальні турніри й результати не очищаються.

## Спрощений режим та публікація

В обліковому записі можна вибрати зелений, фіолетовий, синій, бірюзовий або рожевий акцент. Спрощений режим увімкнений типово: рейтинги приховано, але збережено в профілях. Основна форма турніру містить назву, кількість турів, коефіцієнти та гравців. Порожня назва заповнюється автоматично з номером і датою до хвилини.

Після закриття туру наступний тур створюється окремою кнопкою: між турами швейцарського турніру або арени можна додати гравців із початковими очками, зняти учасника чи повернути його. У повному режимі попередній Elo перераховується після кожного туру; остаточні рейтинги можна підтвердити й записати в профілі після завершення. Повернення до попереднього стану відновлює підтверджені значення, якщо їх не змінювали вручну.

У меню турніру є «Посилання для батьків»: постійна сторінка з поточними та минулими парами і місцями. Публікація використовує [окремий сервіс](live-service/README.md). Зміни надсилаються автоматично, поки застосунок відкритий і має інтернет. Резервні копії можна зберігати у файл або в хмару та відновлювати на іншому пристрої за приватним кодом доступу. Google OAuth поки не налаштовано.
